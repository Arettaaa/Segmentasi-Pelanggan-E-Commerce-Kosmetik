\# Proyek Big Data — Segmentasi Pelanggan E-Commerce



\## Deskripsi

Proyek ini melakukan segmentasi pelanggan berdasarkan riwayat aktivitas pada e-commerce menggunakan Apache Spark dan algoritma K-Means.



\## Dataset

E-Commerce Events History in Cosmetics Shop dari Kaggle, dengan data periode Oktober 2019 hingga Februari 2020.



\## Teknologi

\- Hadoop HDFS

\- Apache Spark dan PySpark

\- Spark MLlib — K-Means Clustering

\- PostgreSQL

\- Python dan Streamlit

\- Plotly



\## Alur Pemrosesan

1\. Menyimpan dataset di HDFS.

2\. Membersihkan dan memproses data menggunakan Spark.

3\. Membentuk fitur pelanggan berdasarkan aktivitas transaksi.

4\. Melakukan segmentasi pelanggan menggunakan K-Means.

5\. Menyimpan hasil segmentasi ke PostgreSQL.

6\. Menampilkan hasil melalui dashboard Streamlit.
