Sensitivitas fitur

Dampak menghapus session_count

Tiga pasangan fitur berkorelasi di atas 0,8: purchase_count dengan total_spend, view_count dengan session_count, serta cart_count dengan remove_count. Model tanpa session_count memberi silhouette lebih tinggi tetapi partisi cukup berbeda, sehingga model tujuh fitur dipertahankan agar profil segmen tetap lengkap.

Konfigurasi Spark dan data
Catatan evaluasi

Silhouette dihitung dengan squared Euclidean distance (default Spark ClusteringEvaluator) pada sampel 10% data, dengan pengaturan sama untuk K-Means dan Bisecting K-Means. Nilai silhouette bukan ukuran akurasi klasifikasi.

Buyer rate per segmen merupakan profil deskriptif, bukan ukuran kebenaran model, karena purchase_count termasuk fitur input clustering.

Ditemukan 16 pelanggan dengan total_spend negatif akibat price negatif pada data mentah; nilai dipotong ke nol sebelum transformasi log1p.

Keterbatasan: data historis Okt 2019 – Feb 2020, segmentasi memakai agregasi seluruh periode, tidak ada label segmen aktual sebagai ground truth, dan K-Means sensitif terhadap inisialisasi centroid.

Dataset: eCommerce Events History in Cosmetics Shop (Kaggle) · Pipeline batch processing pada Docker
